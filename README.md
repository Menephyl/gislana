# Gislana Psicóloga - Landing Page

Uma landing page moderna, responsiva e interativa desenvolvida para **Gislana Arantes (CRP-04/71925)**, psicóloga especialista em Terapia Cognitivo-Comportamental (TCC), com foco em Ansiedade e Autoestima.

## 🚀 Sobre o Projeto

O objetivo deste projeto foi criar um ambiente acolhedor, seguro e com uma identidade visual única (incorporando elementos sutis do universo geek/gamer, como "Status de Habilidade" e "Missões") para conectar a psicóloga ao seu público-alvo de forma leve e inovadora. A página reduz o atrito e a ansiedade na busca por terapia através de uma interface clara e gamificada.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Semântica estruturada e acessibilidade (SEO, Open Graph e Twitter Cards otimizados).
- **CSS3:** Estilização modular, CSS Variables, Flexbox, Grid Layout e design totalmente responsivo (Mobile-first). Animações suaves e micro-interações para engajamento.
- **JavaScript (Vanilla):** Lógica de interface sem frameworks pesados, incluindo:
  - Navegação responsiva (Menu Hamburger).
  - Modal interativo de agendamento em múltiplas etapas (Calendário de disponibilidade, formulário de contato e resumo).
  - Carrossel dinâmico para integração visual com o Instagram.

## ✨ Funcionalidades

- **Design Gamificado:** Seções criativas como "Missões Disponíveis" e "Status de Habilidade" que desmistificam a terapia.
- **Responsividade Total:** Adaptável perfeitamente de telas ultrawide até dispositivos mobile extremamente pequenos (resoluções de 320px).
- **Agendamento Interativo:** Modal step-by-step para o usuário escolher datas, preencher dados e enviar uma mensagem formatada diretamente para o WhatsApp da psicóloga.
- **Carrossel de Conteúdo:** Exibição elegante de dicas e posts do Instagram.
- **Otimização SEO:** Meta tags configuradas para melhor ranqueamento e compartilhamento nas redes sociais.
